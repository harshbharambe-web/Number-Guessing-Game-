# 🎯 Number Guessing Game

A simple and interactive **Number Guessing Game** built using **HTML, CSS, and JavaScript**.  
This mini project focuses on strengthening core JavaScript logic and user interaction.

---

## 🚀 Features

- Generates a random number within a user-defined range
- Allows users to guess the number interactively
- Provides feedback for incorrect guesses
- Includes a quit option to exit the game
- Uses loop-based logic for continuous gameplay

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Basic styling and layout  
- **JavaScript (ES6)** – Game logic and interactivity  

---

## 🧠 Concepts Learned

- JavaScript functions and loops
- Conditional statements and control flow
- Type conversion using `Number()`
- Random number generation using `Math.random()`
- Debugging and logical error handling
- Browser interaction using prompts and alerts

---

## 📂 Project Structure

├── index.html
├── style.css
└── script.js

## ▶️ How to Run

1. Clone the repository  
2. Open `index.html` in any web browser  
3. Click **Start Game** and follow the prompts
